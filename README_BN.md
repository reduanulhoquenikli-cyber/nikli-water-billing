# নিকলী সদর পানির বিল ব্যবস্থাপনা — QR + OTP স্টার্টার

এটি একটি **প্রাথমিক সফটওয়্যার স্টার্টার**, লাইভ সরকারি ওয়েবসাইট নয়। ইউনিয়ন পরিষদের লিখিত অনুমোদন, যাচাইকৃত তথ্য, নিরাপত্তা পর্যালোচনা এবং HTTPS-সহ হোস্টিং ছাড়া বাস্তব গ্রাহকের তথ্য দিয়ে চালু করবেন না।

## এই সংস্করণে
- কর্মকর্তা লগইন ছাড়া প্রশাসনিক পৃষ্ঠা দেখা যায় না
- গ্রাহকের নাম, ঠিকানা, সংযোগ নম্বর ও নিবন্ধিত মোবাইল নম্বর সংরক্ষণ
- কর্মকর্তা গ্রাহকের মোবাইল নম্বর যোগ ও আপডেট করতে পারেন; পরিবর্তনের অডিট রেকর্ড হয়
- মাসিক বিল তৈরি, বকেয়া এবং পরিশোধের অবস্থা দেখানো
- প্রাথমিক মাসিক বিল ১৮০ টাকা; অ্যাডমিন হার বদলালে তা ভবিষ্যতে তৈরি বিলে প্রযোজ্য
- প্রতিটি বিলে অনুমান করা কঠিন, র‌্যান্ডম QR টোকেন
- QR স্ক্যানের পর OTP যাচাই সফল হলে শুধু সেই বিলের তথ্য দেখানো
- OTP ৬ সংখ্যার, ৫ মিনিট কার্যকর, সর্বোচ্চ ৫টি ভুল চেষ্টা; পুনরায় OTP পাঠাতে ৬০ সেকেন্ড অপেক্ষা
- QR ছবির লিংক শুধু লগইন করা কর্মকর্তার জন্য
- OTP এবং গ্রাহকের মোবাইল পরিবর্তনের অডিট ইভেন্ট
- SQLite ডেটাবেস; অনলাইন পেমেন্ট এখনো যুক্ত নয়
- গ্রাহক যাচাই পাতায় ডাউনলোড/প্রিন্ট বাটন নেই (তবে স্ক্রিনশট নেওয়া পুরোপুরি ঠেকানো যায় না)

## প্রয়োজনীয় সফটওয়্যার
Node.js 20 বা নতুন সংস্করণ।

## চালানোর নিয়ম
1. ZIP Extract করুন এবং প্রকল্প ফোল্ডারে যান।
2. `npm install` চালান।
3. `.env.example` কপি করে `.env` করুন।
4. `SESSION_SECRET` এবং `OTP_SECRET`-এ আলাদা, দীর্ঘ ও অনন্য random secret দিন।
5. অ্যাডমিন পাসওয়ার্ডের bcrypt hash তৈরি করুন:
   `node -e "require('bcryptjs').hash('আপনার-শক্তিশালী-পাসওয়ার্ড',12).then(console.log)"`
   ফলাফল `ADMIN_PASSWORD_HASH`-এ বসান। আসল পাসওয়ার্ড কোডে রাখবেন না।
6. স্থানীয় পরীক্ষার জন্য `SMS_GATEWAY_MODE=console` রাখুন। OTP সার্ভারের টার্মিনালে দেখা যাবে; এটি শুধু development/testing-এর জন্য।
7. `npm start` চালান এবং `http://localhost:3000` খুলুন।
8. অ্যাডমিন লগইন করে গ্রাহক তৈরি করুন। OTP ব্যবহারের আগে গ্রাহকের সঠিক মোবাইল নম্বর যোগ করুন।
9. বিল তৈরি হলে অ্যাডমিনের সাম্প্রতিক বিল তালিকা থেকে **QR ছবি** খুলে ডাউনলোড/প্রিন্ট করে বিলের সঙ্গে যুক্ত করুন। QR লিংক তৈরির জন্য `.env`-এর `PUBLIC_BASE_URL` অবশ্যই বাস্তব ডোমেইনের সঙ্গে মিলতে হবে।

## পরে SMS গেটওয়ে চালু করার নিয়ম
এই প্রকল্পে একটি সাধারণ REST/JSON SMS adapter আছে। গেটওয়ে যদি নিচের অনুরোধ-ফরম্যাট সমর্থন করে, `.env`-এ এগুলো যোগ করলেই `http` mode ব্যবহার করতে পারবেন:

```env
NODE_ENV=production
PUBLIC_BASE_URL=https://আপনার-সরকারি-ডোমেইন
SMS_GATEWAY_MODE=http
SMS_GATEWAY_URL=https://provider.example/api/sms
SMS_GATEWAY_API_KEY=আপনার-গোপন-api-key
SMS_GATEWAY_SENDER_ID=আপনার-অনুমোদিত-sender-id
```

সিস্টেম `POST` JSON পাঠায়:

```json
{"to":"গ্রাহকের-মোবাইল","message":"OTP message","sender_id":"configured sender id"}
```

এবং `Authorization: Bearer <API_KEY>` header ব্যবহার করে। **সব SMS provider একই API format ব্যবহার করে না।** আপনার নির্বাচিত provider-এর API যদি আলাদা JSON field, header, বা authentication চায়, `src/server.js`-এর `sendSms()` function-এ সেই provider অনুযায়ী adapter সামান্য বদলাতে হবে। provider বেছে নেওয়ার পর তার API documentation দেখে এই mapping যাচাই করুন। API key কখনো frontend/HTML-এ রাখবেন না। Production-এ `console` mode স্বয়ংক্রিয়ভাবে বন্ধ থাকে।

## নিরাপত্তা ও বাস্তব ব্যবহারের আগে
- HTTPS এবং production session store ব্যবহার করুন; default in-memory session store বহু-সার্ভার/রিস্টার্টের জন্য উপযুক্ত নয়।
- production-grade rate limiting, CSRF protection, নিরাপদ admin role separation/MFA, backup/restore পরীক্ষা এবং security review সম্পন্ন করুন।
- OTP গেটওয়ে provider-এ delivery receipt/webhook ও ব্যর্থ SMS monitoring প্রয়োজন হতে পারে।
- OTP যাচাইয়ের পরে কেবল প্রয়োজনীয় বিলের তথ্য দেখান; URL token ব্যক্তিগত তথ্য বহন করে না, কিন্তু QR যার হাতে যাবে সে OTP পাওয়ার ব্যবস্থা/নিবন্ধিত মোবাইলের নিয়ন্ত্রণ ছাড়া বিল দেখতে পারবে না।
- QR token ও database backup গোপন রাখুন; QR token ফাঁস হলে OTP স্তর থাকলেও অপব্যবহারের চেষ্টা হতে পারে।
- বাস্তব ব্যবহারের আগে ইউনিয়ন পরিষদের লিখিত অনুমোদন, গোপনীয়তা নীতি, ডেটা সংরক্ষণ নীতি এবং স্থানীয় আইন যাচাই করুন।
- অনলাইন পেমেন্ট, কর্মকর্তা-ভিত্তিক একাধিক ভূমিকা এবং পূর্ণাঙ্গ payment/audit workflow এখনো production-ready নয়।

## ডেটাবেস
প্রথম চালু হলে `data/water-billing.sqlite` তৈরি হবে। পুরোনো starter database থাকলে `bills.qr_token` column যোগ করে পুরোনো বিলে random token তৈরি করার migration চলে। নিয়মিত encrypted backup নিন।
